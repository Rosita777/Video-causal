# Planned mechanism set v1

The steel-ball fracture source is replaced by a wooden mallet to reduce ball-object bias while retaining the same fracture mechanism.

| Mechanism | Source object | Receiver | Causal footprint | Status |
| --- | --- | --- | --- | --- |
| Water impact | Water droplet | Water surface | Splash and ripples | Retain |
| Rigid collision | Red rubber ball | Upright wooden blocks | Receiver falls | Retain |
| Brittle fracture | Wooden mallet | Glass cup | Cracks and fragments | Retain; Wan smoke valid |
| Powder impact | Apple | Flour | Flour burst after contact | Retain; Apple v2 Wan strict valid 4/4 |

The planned set contains one liquid source, one ball, one tool, and one fruit. CogVideoX-2B is excluded from this feasibility screen because its prior diverse-object strict validity was 0/4. The four Wan apple v2 samples all show the apple falling before a post-contact flour burst, so the apple mechanism is frozen for the next data-expansion stage.
