\section{Qualitative Results and Failure Cases}
\label{app:qualitative-failures}

\outlineblock{Reviewer question}{
What changes over the full video, how were examples selected, and do the
figures reveal the same limits as the quantitative results?}

\subsection{Deterministic Case-Selection Rule}
\label{app:qualitative-selection}

\outlineblock{Content}{
Freeze a rule that depends only on pre-treatment case metadata and hashed case
identifiers and never reads per-method scores or media. Bind selected case
IDs, prompts, frame indices, Original eligibility, and selection-code hash in
a manifest. Disclose that the rule was frozen after aggregate unblinding, so
the gallery is descriptive rather than pre-unblinding confirmatory evidence.
The rule selects causal, implicit, and specificity case categories; it does
not promise that an output will be a success or failure. Include no
hand-picked replacement after viewing a selected method output.}

\subsection{Seven-Mechanism Causal Comparisons}
\label{app:causal-qualitative}

\outlineblock{Figures G1--G7}{
For each mechanism, use the same rows and frames. Show frames
0, 8, 16, 24, 32, 40, and 48; place a visible divider between Wan and
CogVideoX blocks; annotate source, receiver, and footprint. Keep method names
and row order fixed across all figures.}

\subsection{Specificity Preservation}
\label{app:specificity-qualitative}

\outlineblock{Figures G8--G14}{
Show same-noun noncausal, role-swap or near-causal, and same-footprint
alternative-cause cases. Captions identify what must remain and avoid claiming
preservation when the displayed action or context changes.}

\subsection{Failure Taxonomy}
\label{app:failure-taxonomy}

\outlineblock{Figure G15 and Table G1}{
Use the same temporal grid for residual source, residual footprint, receiver
drift, quality collapse, temporal reappearance, and incorrect suppression of
an alternative cause. Tie every category to atomic fields and mechanism
counts. This failure gallery may use a separately declared outcome-aware,
post-unblinding descriptive rule over canonical failure labels; disclose that
rule, report the full category inventory, and permit no manual replacement.}

\subsection{Supplemental Video Index}
\label{app:video-index}

\outlineblock{Content}{
Provide a machine-readable index or HTML gallery for full videos. The PDF
contains representative temporal grids; it does not duplicate the complete
video inventory as static pages.}

\claimboundary{Captions report visible observations. Avoid a generic phrase
such as \emph{successfully solves} when the source is only partially reduced
or the scene has materially changed.}
