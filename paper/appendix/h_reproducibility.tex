\section{Reproducibility and Artifact Provenance}
\label{app:reproducibility}

The realized experiment is a content-addressed artifact graph rather than a
collection of trusted file names.  Every completed stage binds its inputs and
outputs by SHA-256; implementations are also bound where an existing registry
records them; the additive release layer closes the pre-metric code-binding
gaps.  These commitments identify the realized artifacts; they do not
promise bitwise regeneration under a different CUDA stack or a future hosted
model endpoint.  The graph is complete through the frozen initial human-audit
queue and a clean pre-metric implementation prefix.  Canonical scores,
Original eligibility, shared-capability subsets, formal metrics, and final
paper tables do not yet exist and therefore appear as pending rather than
receiving prospective hashes.

\subsection{End-to-End Artifact Graph}
\label{app:artifact-graph}

Figure~\ref{fig:artifact-graph} separates completed, private, and pending
nodes.  The ontology and static build bind 1,344 target candidates, 294 formal
cases and seeds, a 48-case identification subset, and the 18-run Wan matrix.
Target generation contributes 1,152 new target videos and 192 manifest-bound
Water target videos.  Treatment-blind screening freezes 1,246 source-free targets,
exactly 178 per mechanism.  These targets, 36 preservation bindings, model and
runtime inventories, and cache/run-spec registries feed 18 Wan checkpoints
and seven adapted CogVideoX checkpoints.

The formal cases and checkpoint or baseline registries feed four generation
branches: 294 Wan Original, 684 trained-Wan, 1,176 CogVideoX core, and 294
SAFREE videos.  Path-rebound manifest views change only registered path fields
and retain receipts for each rewrite; the source manifests remain unchanged.
The package builder joins the 2,448 validated outputs only after re-decoding
and hash verification, then creates two independently ordered anonymous
passes and public commitments to the private mappings.  Their completed VLM
scores determine the frozen 3,633-atom initial human queue.

run tests the procedure without guaranteeing identical judgments.

\subsection{Release and Submission Checklist}
\label{app:release-checklist}

During anonymous review, the evaluator-facing public package contains randomized identifiers,
assignments, temporal composites, blank score schemas, the evaluation-code
registry, and commitments to hidden mappings.  It contains no stream, method,
or backbone identity, and its launcher records zero private files opened.  A
human reviewer will receive an isolated copy of
\path{human_audit_stage0/public/} only.  The parent workspace and unsanitized
blind secret, mappings, generation ledger, package receipt, and API
credentials remain outside reviewer copies and the paper-submission tree.
Machine-specific absolute paths may remain in internal handoff documentation,
but release checks reject them from reviewer deliveries and released
manifests; only permitted hashes and sanitized aggregate facts are public.

After human and metric freeze, reproducibility requires more than those
anonymous commitments.  The release must publish a sanitized derivative of
the package-provenance receipt that binds its private parent digest
\texttt{63933393ea04\ldots}, together with de-anonymized canonical/per-case
artifacts sufficient to recompute method-indexed tables, without publishing
the blind secret itself.  The released receipt carries the complete parent
digest; the manuscript prints only its prefix.  Selected target media,
checkpoints, and formal videos must be released where policy permits;
otherwise their manifests, hashes, access conditions, and resulting
reproduction limit must be stated explicitly rather than presenting aggregate
verification as full rerunnability.

The release procedure is:
\begin{enumerate}
  \item during anonymous review, retain every private mapping and secret
        outside the submission and reviewer deliveries;
  \item add and freeze the release-time environment version lock and receipt,
        the 18-receipt inventory, the additive deviation amendment, v2 wrappers, reviewer
        instructions, the full executable-command ledger, the artifact-DAG
        verifier, and final table exporter before viewing canonical metrics;
  \item freeze a clean pre-metric code commit and its stage-to-code/artifact
        manifest, including every component from the preceding item;
  \item complete the initial independent reviews, adjudication, and process
        receipt; run the registered expansion decision; then complete
        reviewer-specific final projections, final adjudication, and a final
        process receipt even when no new rows are added;
  \item materialize canonical scores, eligibility, shared subsets, formal
        metrics, generated tables, and their parent-hash chain;
  \item run the artifact-DAG verifier and submission gate against the exact
        tree to be committed, confirming that no preview root, non-canonical
        manifest, or private path is reachable from the submission driver;
  \item freeze a post-metric artifact-and-paper commit without changing the
        pre-metric scoring code, then bind that commit and its released
        artifacts in an immutable out-of-tree release receipt or Git tag; and
  \item release the sanitized package-provenance receipt,
        de-anonymized canonical/per-case tables, ontology, selected-target
        manifests and treatment-blind screening scores, prompts, formal cases
        and seeds, identification subset, rubrics, schemas, code, audit and
        adjudication provenance, available media/checkpoints, aggregate
        results, reproduction commands, and explicit availability limits.
\end{enumerate}

The materialized pre-metric prefix completes items 2--3: its manifest
self-digest begins \texttt{b3892f5d6b59}, and the independently rerun prefix
DAG verifier reports 40 materialized nodes, nine pending human/final nodes,
six declared-unavailable upstream authorities, and one private commitment.
Items 4--8 remain pending.
