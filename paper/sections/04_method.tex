\section{\methodname}
\label{sec:method}

\outlineblock{Section roadmap}{
First construct dynamic source-free targets. Then randomize only the identity
occupying the causal-source slot while keeping each target fixed. Finally
distill the edited model toward the frozen counterfactual teacher and preserve
unrelated behavior. Every component must map to a later control or guardrail.}

\subsection{Structured Dynamic Counterfactual Pairs}
\label{subsec:counterfactual-pairs}

\outlineblock{Failure mode and design response}{
A static clean frame, spatial mask, or independently worded negative prompt
does not specify a plausible dynamic world after removing an event source.
Construct each factual prompt from structured source, trigger, receiver,
footprint, and context fields, and pair it with an independently generated
dynamic source-free target. State that factual and target videos are not
pixel-aligned.}

\outlineblock{Required details}{
Explain the treatment-blind candidate screen, 178 selected erasure bindings
per mechanism, 36 shared preservation bindings, frozen target latents, and
counterfactual-teacher caches. Move templates, rejection reasons, hashes, and
examples to \appref{app:counterfactual-data}.}

\subsection{Randomizing the Causal-Source Slot}
\label{subsec:source-slot-randomization}

\outlineblock{Core intervention}{
For each erasure binding, replace the original source identity with a
deterministically assigned identity from the disjoint 64-item mechanism bank.
Rebuild the prompt from structured fields rather than substring replacement.
The source identity changes; the source-free target, receiver, trigger type,
footprint semantics, and training trajectory remain fixed.}

\outlineblock{Mechanistic hypothesis}{
Across bindings, the stable supervisory relation is that whichever entity
occupies the causal-source slot and the footprint that depends on it should be
absent in the no-source world. Contrast this with ordinary paraphrasing, but
defer the behavioral test to \S\ref{subsec:role-or-word}.}

\label{subsec:training-objectives}

\outlineblock{Single-factor comparison}{

not one universal seven-mechanism model.}
